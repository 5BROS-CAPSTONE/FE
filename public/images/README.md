# Landscape photography

Images are downloaded as optimized WebP assets and served locally; the site does not request the Unsplash image CDN at runtime.

- `terraces-hero.webp`, `terraces-mobile.webp`: [Aerial green rice field on Unsplash](https://unsplash.com/photos/an-aerial-view-of-a-green-rice-field-5VtMfxRGhso), image ID `photo-1646928998317-6855a396e55b`.
- `terraces-detail.webp`: [Aerial agricultural field on Unsplash](https://unsplash.com/photos/hdD1ZP1PzqI), image ID `photo-1557445796-184d83fc49b9`.

These are illustrative landscape photographs, not imagery of the demo customer's actual Farm or live operational data.
